One bit of CI truth:
lit or dark.

A light names whether an upstream project’s latest relevant CI run mapped to lit or dark. Encoding is active-low — like a hardware signal line: lit = 0, dark = 1.

●
lit
bit 0
○
dark
bit 1

What the words mean

lit

The latest relevant completed GitHub Actions run (push) has conclusion === "success". Logical value 0.

dark

That run has any other conclusion. Logical value 1. Dark is about the project’s own CI — not “download failed”.

Map once from GitHub’s conclusion field, then use only lit and dark. Full write-up: white paper · SPEC.md.

Reproduce it

This public repo has a file LIGHT that is exactly lit or dark. The workflow exits 0 or 1 so the Actions conclusion matches. A no-deps reader prints the state and bit.

git clone https://github.com/fitzyracing1/lit-dark
cd lit-dark

# Force lit
echo lit > LIGHT
git add LIGHT && git commit -m 'light: lit' && git push
node read-light.mjs fitzyracing1/lit-dark
# expect: ● lit  bit=0

# Force dark
echo dark > LIGHT
git add LIGHT && git commit -m 'light: dark' && git push
node read-light.mjs fitzyracing1/lit-dark
# expect: ○ dark  bit=1

Merged fixes

Each entry is an upstream pull request, merged by the project’s maintainers, that took a light that was dark and made it lit upstream. Data: merged.json.

  • ● cnpm/cnpmcore#1161 — ci: run test-mysql57-s3-nfs against a local S3Mock instead of the remote bucket
    Merged 2026-10-12 by @fengmk2

    Was dark: cnpmcore's test-mysql57-s3-nfs CI job was dark on master: the remote S3 bucket it used answered every request with HTTP 530, so the job stayed dark run after run.

    Lit upstream: the job now runs against a local S3Mock service container instead of the remote bucket. The first master run after the merge (Node.js CI 38202391845) has all three test-mysql57-s3-nfs jobs lit.

The light computer

Eight lights pack into one active-low byte. A small CPU and programs consume that byte — suggest-only actions when lights are dark, never auto-acting.

  • This site / repo — public spec and proof
  • fitzyracing1/light-computer — implementation (private for now)
  • fitzyracing1/light-programs — suggest-only programs (private for now)
  • fitzyracing1/patch-cloud — opt-in registry that can serve a fork while a mapped light is dark (private for now)
